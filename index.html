Questions

Before you scan

Do I need to know how to code to use this? +
No. Paste your site's link and read the plain-English report. If you want a fix done for you automatically, that part does need a connected GitHub repo — but it's optional.
Will this slow down or break my live site? +
No. Scanning only reads your site the way a visitor's browser would; it never changes anything unless you approve a fix yourself.
What AI tools does this work with? +
Any site, regardless of what built it — including apps made with Lovable, Cursor, Bolt, v0, Replit, and Windsurf.
Is my data kept private? +
Yes. We don't sell or share scan results, and code is never used to train AI models.
What does it cost? +
Your first scan is free. Ongoing weekly monitoring and the trust badge start at $19/month.
